# PEPE/DOGE 突破雷达

基于历史量化研究的行情观测型 Web 应用。它把 21 个历史「突破」波段样本的量化特征，转成一套**确定性、可解释、可回放**的实时观测雷达：持续追踪 PEPE 与 DOGE 的蓄势、临界、突破、过热与失效状态，并用「机会分 / 风险分 / 证据链」代替模糊判断。

> 本项目**不构成任何投资建议**，**不输出胜率、准确率、假突破概率或收益承诺**。

---

## 它能做什么

- **实时雷达**：对 PEPE / DOGE 各自计算机会分（0–100）、过热/失效风险分（0–100）与六态状态（观望 → 蓄势 → 临界 → 突破确认 → 等待回踩 → 失效）。
- **证据可解释**：每个状态、每项评分都给出「数值 + 证据来源 + 时间戳 + 新鲜度」，不画魔法图。
- **历史样本矿场**：21 个研究波段（PEPE 11 + DOGE 10），每个都能查看量化指标、窗口 K 线、相对 BTC 强度与原始截图。
- **相似性引擎**：把「蓄势压缩率、量比、相对强度、资金费率、BTC 环境」五维特征向量化，回答「当前最像历史上的哪一波」。
- **阈值回放实验**：在方法论页用本地快照重放引擎，观察候选阈值如何改变判定（重放，非预测）。
- **优雅降级**：实时数据接口不可用时，自动回退为研究快照，历史模式完整可用。

## 页面

| 路由 | 说明 |
|---|---|
| `/` | 总览：实时雷达 + 历史样本 |
| `/asset/pepe`、`/asset/doge` | 单币详情 |
| `/history` | 历史样本矿场（可筛选币种/波段周期） |
| `/history/:id` | 事件详情：指标 + 窗口图 + 原始截图 |
| `/similarity` | 相似性：历史特征空间 + 当前像谁 |
| `/methodology` | 方法论：指标、状态机、评分权重、阈值回放 |

## 技术栈

Next.js 16 (App Router) · React 19 · TypeScript 5 · Tailwind CSS 4 · shadcn/ui · 自绘 SVG K 线图 · 服务端数据代理。

## 本地运行

```bash
pnpm install
bash scripts/dev.sh          # 开发模式（tsx watch src/server.ts）
```

运行测试（指标单测 + 21 事件回归）：

```bash
pnpm test
```

## 目录速览

```
src/lib/          指标纯函数、状态机、评分、历史事件、第三方数据代理、快照载入
src/app/          页面路由 + REST 接口（/api/*）
src/components/   业务组件（自绘 K 线图、状态徽章、评分环、雷达卡等）
src/data/         研究快照 JSON（21 事件指标 + 3 币种 4H K 线 + 资金费率）
public/screenshots/  21 张原始截图（P01..P11 / D01..D10）
```

## 数据来源

- 历史快照：研究包内 `event_metrics.csv`（21 事件）、OKX 4H K 线、Binance 资金费率。
- 实时：OKX（K 线 / 指数价）与 Binance（资金费率），由服务端 `src/lib/market-client.ts` 代理：超时、内存缓存、限频去重、错误分类。
- 时间：UTC 存储，页面按 Asia/Shanghai 显示。

## 已知缺口（如实标注，不补造）

- 未纳入「失败突破」样本与「普通行情」对照窗口，当前只展示 21 个波段样本本身。
- 沙箱/部分部署环境无法访问 OKX / Binance 外网时，实时雷达显示「实时数据不可用」，历史维度仍完整可用。
